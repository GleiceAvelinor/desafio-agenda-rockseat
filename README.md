📁 Gerenciador de Contatos em Python
Este é um projeto prático desenvolvido para consolidar os fundamentos da linguagem Python, focado em lógica de programação, manipulação de estruturas de dados (listas e dicionários) e interação via terminal.

🚀 Sobre o Desafio
O objetivo principal foi criar uma agenda que permitisse ao usuário gerenciar seus contatos através de um menu interativo, aplicando o conceito de CRUD (Create, Read, Update, Delete).

🛠️ Funcionalidades
Adicionar Contatos: Cadastro de nome, telefone e e-mail.

Listar Contatos: Visualização organizada com numeração automática.

Editar Contatos: Atualização de dados existentes de forma seletiva.

Favoritar: Sistema para marcar e desmarcar contatos como favoritos (exibidos com um símbolo ★).

Listar Favoritos: Filtro rápido para exibir apenas contatos marcados.

Remover Contatos: Exclusão segura baseada no índice da lista.

🧠 Conceitos Aplicados
Para construir este desafio, utilizei os seguintes pilares da programação:

Estruturas de Repetição (while): Para manter o programa rodando até que o usuário decida sair.

Estruturas de Condição (if/elif/else): Para o processamento de escolha do menu.

Dicionários e Listas: Armazenamento estruturado dos dados dos contatos.

Enumerate: Utilizado para fornecer índices reais ao usuário, facilitando a escolha de qual contato manipular.

Tratamento de Erros (try/except): Prevenção de quebras no programa caso o usuário digite um caractere inválido onde se espera um número.

💻 Como Executar
Certifique-se de ter o Python 3 instalado em sua máquina.

Clone o repositório:

Bash
git clone https://github.com/seu-usuario/gerenciador-contatos-python.git
Acesse a pasta do projeto:

Bash
cd gerenciador-contatos-python

Bash
